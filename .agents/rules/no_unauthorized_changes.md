# 절대 원칙: 기존 작업/동작 임의 변경 및 되돌리기 영구 금지

사용자가 직접 명시적으로 명령하거나 지시하지 않은 이상, 다음 사항을 **절대로 엄격히 준수**하십시오:

1. **기존 완성된 작업 보존**: 이전에 이미 구현되었거나 정상적으로 동작하던 기능, 화면, 전송/공유 흐름, 로직, UI 등을 절대로 임의로 변경하거나 이전 상태로 되돌리지 마십시오.
2. **사이드 이펙트 엄격 차단**: 새로운 기능 추가, 성능 최적화, 파일 분리(리팩토링) 작업을 수행할 때, 요청받은 특정 기능 외의 다른 기존 화면이나 공용 로직에 부작용이 가지 않도록 철저히 격리하십시오.
3. **요청한 범위만 정확히 수정**: 사용자가 직접 지정하여 수정을 요청하지 않은 영역은 단 한 줄의 코드도 임의로 간섭하거나 수정하지 마십시오.
